# Kali Linux Cybersecurity Lab

## Overview

This repository documents my journey into cybersecurity and ethical hacking, beginning with setting up Kali Linux in Oracle VirtualBox.

As a Computer Science student, I want to strengthen my understanding of operating systems, computer networks, and cybersecurity through practical, hands-on learning.

This project represents my first step toward building a personal cybersecurity lab where I can practise security concepts in a controlled environment.

## Project Objectives

- Learn how to install and configure Kali Linux in a virtual machine.
- Develop confidence using the Linux command line.
- Strengthen my understanding of networking fundamentals.
- Explore cybersecurity tools and their legitimate uses.
- Document practical exercises, challenges, and lessons learned.

| Guest operating system | Kali Linux |

## Setup Experience

Setting up this environment was an important learning experience for me.

I installed Oracle VirtualBox and its Extension Pack, downloaded the Kali Linux virtual machine, extracted the downloaded archive, and configured the virtual machine to run on my laptop.

During the process, I learned more about virtualisation and how a virtual machine allows an operating system to run inside another operating system without replacing the host system.

The experience also helped me appreciate the importance of following installation instructions, checking system requirements, and configuring resources carefully when working with limited hardware.

Completing the setup has given me a foundation for exploring Linux, networking, and practical cybersecurity exercises.
